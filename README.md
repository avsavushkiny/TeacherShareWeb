# TeacherShare Web

TeacherShare Web — веб-приложение для передачи материалов с ноутбука на компьютер, подключённый к проектору, через локальную сеть.

## Возможности

- Захват всего экрана или отдельного окна через браузер.
- Выделение прямоугольной области в предпросмотре захваченного экрана.
- Передача снимков на компьютер с проектором.
- Автоматическое обновление передаваемого изображения.
- Загрузка изображения с ноутбука и показ его на проекторе.
- Создание текстового слайда с настройкой размера шрифта, цвета текста и фона.
- Полноэкранный режим на компьютере с проектором.
- Запуск сервера в Windows с помощью `start-server.bat`.

> Приложение передаёт изображения, а не непрерывный видеопоток. При захвате экрана браузер получает поток кадров, из которого формируются изображения для отправки.

## Требования

- Windows на ноутбуке, который запускает сервер.
- Node.js LTS и npm: <https://nodejs.org/>
- Современный браузер, например Google Chrome или Microsoft Edge.
- Ноутбук и компьютер с проектором должны быть подключены к одной локальной сети.

## Быстрый запуск на Windows

1. Распакуйте архив проекта в отдельную папку, например `C:\TeacherShareWeb`.
2. Установите Node.js LTS, если он ещё не установлен.
3. Дважды щёлкните `start-server.bat`.
4. При первом запуске BAT-файл должен установить зависимости проекта, после чего запустить сервер.
5. Не закрывайте окно консоли, пока приложение используется.

Если BAT-файл не запускается, откройте командную строку в папке проекта и выполните:

```bat
npm install
npm start
```

Сервер использует порт **8085**.

## Открытие страниц

### На ноутбуке — передатчик

Откройте в браузере:

<http://localhost:8085/sender.html>

### На компьютере с проектором — приёмник

Узнайте IP-адрес ноутбука в окне сервера. Затем на компьютере с проектором откройте:

```text
http://IP-АДРЕС-НОУТБУКА:8085/receiver.html
```

Например:

```text
http://192.168.1.50:8085/receiver.html
```

Замените `192.168.1.50` на фактический IPv4-адрес ноутбука в вашей локальной сети.

## Захват экрана

1. На ноутбуке откройте страницу передатчика.
2. Нажмите **«Выбрать экран»**.
3. В системном окне браузера выберите экран или окно и подтвердите выбор.
4. При необходимости выделите прямоугольную область в предпросмотре.
5. Запустите передачу изображения. Если включён автоматический режим, снимки будут отправляться периодически.
6. На компьютере с проектором откройте страницу приёмника.

Браузер запросит разрешение на захват экрана. Это ограничение безопасности браузера.

## Передача готового изображения

1. На странице передатчика нажмите **«Открыть изображение…»**.
2. Выберите поддерживаемый браузером файл изображения.
3. Проверьте предпросмотр.
4. Нажмите кнопку передачи изображения.
5. Изображение появится на странице приёмника.

Изображение подгоняется под область отображения с сохранением пропорций.

## Текстовый слайд

1. Перейдите к разделу текстового слайда.
2. Введите нужный текст.
3. Настройте размер шрифта и цвет текста.
4. Выберите цвет фона.
5. Нажмите кнопку показа текста на проекторе.

После изменения текста или параметров нажмите кнопку показа ещё раз, чтобы отправить обновлённый слайд.

## Полноэкранный режим

На компьютере с проектором используйте кнопку полноэкранного режима на странице приёмника. Если браузер не позволяет перейти в полноэкранный режим автоматически, нажмите кнопку или используйте `F11`.

## Настройка брандмауэра Windows

Если страница приёмника не открывается с другого компьютера:

1. Убедитесь, что оба компьютера находятся в одной локальной сети.
2. Проверьте IP-адрес ноутбука.
3. Разрешите входящие подключения Node.js или TCP-порта **8085** в брандмауэре Windows для частной сети.
4. Не отключайте брандмауэр полностью.
5. Проверьте, что сервер работает и окно консоли не закрыто.

## Структура проекта

```text
TeacherShareWeb/
├── package.json
├── server.js
├── start-server.bat
├── README.md
└── public/
    ├── index.html
    ├── sender.html
    ├── receiver.html
    ├── css/
    │   └── style.css
    └── js/
        ├── sender.js
        └── receiver.js
```

Назначение основных файлов:

- `server.js` — веб-сервер и API для публикации текущего изображения.
- `start-server.bat` — запуск сервера в Windows.
- `public/sender.html` — интерфейс передатчика.
- `public/js/sender.js` — захват экрана, выбор области, загрузка изображения и подготовка текстового слайда.
- `public/receiver.html` — страница для компьютера с проектором.
- `public/js/receiver.js` — получение и отображение текущего изображения.
- `public/css/style.css` — оформление интерфейса.
- `package.json` — зависимости и команды запуска.

## Устранение неполадок

### Кнопка захвата экрана ничего не делает

- Откройте передатчик по адресу `http://localhost:8085/sender.html` непосредственно на ноутбуке.
- Используйте актуальный Chrome или Edge.
- Обновите страницу сочетанием `Ctrl+F5`.
- Проверьте консоль браузера: `F12` → **Console**.

### На проекторе пустой экран

- Убедитесь, что передатчик отправил изображение.
- Проверьте адрес приёмника и IP-адрес ноутбука.
- Проверьте, что порт 8085 разрешён в брандмауэре.
- Обновите страницу приёмника.

### Команда `npm` не найдена

Установите Node.js LTS с <https://nodejs.org/>, затем закройте и заново откройте командную строку.

### BAT-файл выдаёт ошибку

Проверьте, что `start-server.bat` находится в корневой папке проекта рядом с `package.json`. Для просмотра подробного сообщения запустите BAT-файл из открытой командной строки.

## Безопасность и ограничения

- Приложение рассчитано на использование в доверенной локальной сети.
- Если в текущей версии не настроена авторизация, любой пользователь с доступом к серверу в сети потенциально может обратиться к его API. Не публикуйте порт сервера в интернете.
- Захват экрана выполняется с разрешения пользователя через браузер.
- Передача выполняется изображениями; задержка обновления зависит от частоты отправки, размера снимка и сети.
- Перед использованием в учебной аудитории рекомендуется проверить работу на обоих компьютерах.
