Передатчик

Выберите экран, выделите область и отправьте её изображение на проектор.

Изображение

Выберите изображение на ноутбуке. Оно будет показано на проекторе целиком, с сохранением пропорций.

Текстовый слайд

Текст размещается по центру с автоматическим переносом строк. Для изменения текста нажмите кнопку ещё раз.

Захват экрана

Откройте изображение, создайте текстовый слайд или нажмите «Выбрать экран».

Для захвата экрана нажмите «Выделить область», затем протяните мышью прямоугольник по предварительному просмотру. Нажмите Esc, чтобы отменить выделение.
