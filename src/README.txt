TEACHERSHARE WEB
================

Назначение
----------
Локальная система передачи изображений и текстовых слайдов с ноутбука на ПК,
подключённый к проектору. Сервер запускается на ноутбуке.

Быстрый запуск в Windows
------------------------
1. Установите Node.js LTS, если он ещё не установлен: https://nodejs.org/
2. Распакуйте весь архив в отдельную папку, например C:\TeacherShareWeb.
3. Дважды щёлкните start-server.bat.
4. При первом запуске BAT-файл установит зависимости. Для этого нужен Интернет.
5. Не закрывайте открывшееся окно консоли во время работы сервера.
6. На ноутбуке откройте http://localhost:8085/sender.html
7. На ПК с проектором откройте http://IP-АДРЕС-НОУТБУКА:8085/receiver.html
   Точный IP-адрес ноутбука выводится в окне сервера. Оба компьютера должны
   находиться в одной локальной сети.

Возможности передатчика
-----------------------
1. Открыть изображение: нажмите «Открыть изображение…», выберите файл и
   нажмите «Передать изображение». Изображение целиком появится на проекторе.
2. Текстовый слайд: введите текст, настройте размер шрифта и цвета текста/фона,
   нажмите «Показать текст на проекторе». Длинный текст автоматически переносится.
   После изменения параметров нажмите кнопку ещё раз, чтобы обновить проектор.
3. Захват экрана: нажмите «Выбрать экран», выберите экран/окно в диалоге браузера,
   нажмите «Выделить область», выделите прямоугольник и отправьте снимок.
   Для периодической передачи захваченной области включите автообновление.
4. «Остановить передачу» убирает изображение с экрана проектора.
5. На странице проектора можно включить полноэкранный режим.

Если кнопка захвата экрана не работает
--------------------------------------
Открывайте передатчик в актуальном Chrome или Edge по адресу localhost:
http://localhost:8085/sender.html
Браузер должен получить разрешение пользователя на захват экрана.

Брандмауэр Windows
------------------
Если ПК с проектором не открывает страницу, разрешите Node.js/входящие TCP-
подключения к порту 8085 для частной сети Windows. Не отключайте брандмауэр
полностью. Убедитесь, что оба компьютера подключены к одной доверенной сети.

Ограничения и безопасность
-------------------------
Приложение рассчитано на использование в доверенной локальной сети. В этой
версии нет авторизации и шифрования, поэтому не публикуйте порт в Интернет.
Изображения передаются как снимки, а не как видеопоток.
